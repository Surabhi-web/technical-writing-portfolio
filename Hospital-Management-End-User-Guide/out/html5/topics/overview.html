Hospital Management System

Overview of the Hospital Management System user interface and the main tasks covered in this guide.

This guide helps hospital staff use the Hospital Management System to view patient information, review appointments, and send messages.

The examples in this portfolio project use the OpenEMR demonstration environment. The interface may vary depending on user role and system configuration.

Audience

This guide is intended for hospital staff who use the system to manage day-to-day patient and appointment information.

Before you begin

  • Obtain the login credentials provided by your organization.
  • Use an approved browser and a secure network connection.
  • Do not share patient information or login credentials with unauthorized users.
