View and Search Appointments

Review future appointments and use the appointment search screen to locate an appointment.

Use the appointment area to review scheduled appointments and narrow the list when you need to find a specific appointment.
  1. Open the appointments area.
  2. Review the listed appointments.
  3. Open the appointment search function when you need to locate a specific appointment.
  4. Enter the available search criteria and run the search.
The system displays appointments that match the search criteria.
