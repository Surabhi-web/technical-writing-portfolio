Read and Send Messages

Review messages and create a new message for a selected patient or recipient.

  1. Open the Message Center.
  2. Review the available messages and select a message to read it.
  3. Select the option to create a new message.
  4. Select the patient or recipient associated with the message.
  5. Enter the message details and send the message.
The message is submitted to the selected recipient or patient record according to the system configuration.
