Contents
- hospital-management-user-guide.ditamap — DITA map / table of contents
- topics/ — DITA concept, task, and reference topics
- screenshots/ — cropped UI screenshots referenced by the topics

Authoring model
- DITA 1.3 topic-based authoring
- Task topics for procedural "How do I?" content
- Concept topic for overview/navigation information
- Reference topic for troubleshooting information
- DITA map for organization and navigation

The project is based on the end-user guide created from the OpenEMR demonstration interface.
The guide intentionally does not include patient registration because an Add New Patient screenshot was not available in the supplied material.

Open the .ditamap in a DITA-aware editor such as Oxygen XML Editor, or process it with a DITA publishing tool such as DITA Open Toolkit.
