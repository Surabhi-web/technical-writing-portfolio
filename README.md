# Technical Writing Portfolio

A collection of technical writing and documentation samples showcasing task-based, user-focused content across healthcare, IT support, and software onboarding domains — built using DITA XML, MadCap Flare, and HTML/CSS.

🔗 **Live portfolio:** [surabhi-web.github.io/technical-writing-portfolio](https://surabhi-web.github.io/technical-writing-portfolio/)

---

## 📁 Projects

### 1. Hospital Management System — End-User Guide
**Tool:** DITA XML → HTML5 (DITA-OT)

**Audience:** Hospital front-desk and ward staff who need to perform day-to-day tasks in the hospital management system.

**Problem solved:** Replaced ambiguous or missing process knowledge with clear, structured, step-by-step documentation — covering login, dashboard navigation, viewing patient information, managing appointments, messaging, and troubleshooting, plus a detailed SOP for patient admission and discharge.

**My role:** Designed the information architecture and authored topic-based content in DITA XML — breaking procedures into reusable topics, organizing them into a logical map, writing step-by-step instructions, and publishing the output as an HTML end-user guide.

📂 [View project](./Hospital-Management-End-User-Guide)

### 2. IT Help Desk Portal
**Tool:** MadCap Flare

**Audience:** Employees who need to request or track IT support.

**Problem solved:** Gave users a self-service path for IT issues — signing in, understanding the dashboard, creating and tracking support tickets, checking system requirements, using the knowledge base, and troubleshooting common problems — reducing reliance on ad hoc requests to the IT team.

**My role:** Authored and structured the help portal content in MadCap Flare, including task-based topics for ticket creation and tracking, a troubleshooting section, and supporting reference content (system requirements, knowledge base).

📂 [View project](./IT-Help-Desk-Portal-MadCap-Flare)

---

### 3. Unity + Visual Studio — Getting Started Guide
**Tool:** HTML/CSS

**Audience:** Beginners setting up Unity and Visual Studio for the first time.

**Problem solved:** Walked first-time users through initial setup and environment configuration step by step, removing the guesswork typically involved in getting a new dev environment running.

**My role:** Authored the getting-started guide from a beginner's perspective, focusing on clear sequencing and plain-language instructions for a non-expert audience.

📂 [View project](./Unity-Visual-Studio-Getting-Started)
