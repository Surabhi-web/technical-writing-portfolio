Running Your First Script

Create a simple C# script, attach it to a GameObject, and confirm it runs inside the Unity Editor.

Complete Installing Unity and Connecting It to Visual Studio before starting this task.

  1. In the Unity Project window, right-click and select Create > C# Script.
    Name the script PlayerGreeting.cs.
  2. Double-click the script to open it in Visual Studio.
  3. Replace the default Start() method with a line that logs a message, then save the file.
    Example: Debug.Log("Hello from Unity!");
  4. Drag the script from the Project window onto any GameObject in the Hierarchy window.
    The script now appears as a component on that GameObject.
  5. Select Play in the Unity toolbar.
    The message appears in the Unity Console window, confirming the script executed successfully.

You have confirmed that Unity and Visual Studio are correctly linked and that scripts written in Visual Studio run as expected inside the Unity Editor.
