Installing Unity and Connecting It to Visual Studio

Install Unity Hub, install the Unity Editor, and configure Visual Studio as your default script editor so you can write and debug C# scripts from within Unity.

Before installing, confirm the workstation meets the following minimum requirements: 64-bit Windows 10/11 or macOS 12+, 8 GB RAM (16 GB recommended), 20 GB free disk space, and a DirectX 11 / Metal-capable graphics card.

Important: Administrator rights are required to complete installation. Confirm this with your IT team before starting if you are on a managed device.
  • Visual Studio 2022 (Community edition or higher)
  • An active internet connection for the initial download

Unity Hub manages your Unity Editor versions and projects. You install Unity Hub first, then use it to install a specific Editor version.

  1. Go to the Unity Personal page and select Get started or Download Unity.


  2. Sign in with a Unity ID, or create a free one if you do not already have one.
    A Unity ID is required to activate a license. Continue with Google, Apple, SSO, or email.


  3. Confirm your operating system and download Unity Hub.
    Unity detects your OS automatically (Windows, in this example) and the download starts right away. If it does not start automatically, select your OS and architecture manually.


  4. Run the downloaded installer.
    On Windows, this opens the Unity Hub Setup wizard. Confirm or browse to a destination folder, check that enough disk space is available, and select Install.


  5. In Unity Hub, select Installs > Install Editor.
    Select the latest LTS (Long-Term Support) version unless your project specifies a different version.
  6. In the module selection screen, enable Microsoft Visual Studio Community if it is not already installed, or enable Visual Studio Editor if Visual Studio is already present.
    The Unity Editor and the selected modules begin downloading.
  7. Once installation completes, open Unity Hub and select New Project.
  8. Choose a template, name the project, and select Create Project.
    Unity creates the project and opens the Editor.
  9. In Unity, go to Edit > Preferences > External Tools and confirm the External Script Editor field is set to Visual Studio.
    If it is not set automatically, select Visual Studio from the dropdown list.
  10. Double-click any .cs script in the Project window to confirm it opens directly in Visual Studio with Unity's C# project references loaded.
    Visual Studio opens with IntelliSense recognizing Unity API classes such as MonoBehaviour, confirming the two applications are correctly linked.

Unity and Visual Studio are now installed and connected. You can write, save, and run C# scripts in Visual Studio and see the results reflected immediately in the Unity Editor.

See Running Your First Script to test the connection end-to-end.
