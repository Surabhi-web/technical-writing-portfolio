Administrator Guide: Configure a Security Policy

Security policies determine how SentinelGate evaluates requests before forwarding them to an AI provider.

  1. Open Security Policies.
  2. Select Create policy or open an existing policy.
  3. Enable the required security controls.
    For this portfolio example, enable prompt-injection protection and sensitive-data detection.
  4. Select the action for blocked requests.
    A blocked request can return an error and create a security event.
  5. Select Save.

The policy is saved and available for assignment to a gateway.

Use metadata-only logging when request content must not be retained.
