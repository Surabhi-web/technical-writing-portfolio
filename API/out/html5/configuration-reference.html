Configuration Reference

Gateway configuration

The following YAML illustrates a gateway configuration.

gateway:
  name: customer-support-gateway
  provider:
    endpoint: https://api.example-llm.com/v1
  security:
    promptInjection: true
    sensitiveDataDetection: true
  logging:
    mode: metadata-only

Parameters

ParameterRequiredDescription
gateway.nameYesUnique gateway identifier.
gateway.provider.endpointYesAI provider base URL.
gateway.security.promptInjectionNoEnables prompt-injection checks.
gateway.security.sensitiveDataDetectionNoEnables sensitive-data checks.
gateway.logging.modeNoControls information retained in security logs.
