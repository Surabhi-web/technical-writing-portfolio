API Reference

POST /v1/gateways/{gatewayId}/responses

Sends input to a configured gateway.

Authentication

Send the API key in the Authorization header using the Bearer scheme.

Request example

POST /v1/gateways/gw_123/responses
Authorization: Bearer <API_KEY>
Content-Type: application/json

{
  "input": "Summarise the deployment steps."
}

Response example

HTTP/1.1 200 OK
Content-Type: application/json

{
  "id": "resp_456",
  "status": "completed",
  "output": "The deployment requires..."
}
