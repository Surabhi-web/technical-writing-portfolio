Troubleshooting

Use the following checks for common gateway and API issues.

Gateway shows Not connected

  • Verify the provider endpoint.
  • Confirm that the API credential is valid.
  • Check outbound network access.
  • Review the event log for the failure reason.

API returns 401 Unauthorized

Verify that the API key is active and sent in the Authorization header.

API returns 429 Too Many Requests

Reduce request frequency and use exponential backoff. Check configured rate limits before retrying.
