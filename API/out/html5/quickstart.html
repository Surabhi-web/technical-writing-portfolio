Quickstart: Configure a Gateway

Use this procedure to configure a development gateway and send a test request.

  1. Sign in to SentinelGate.
  2. Open AI Gateways and select Create gateway.
    Use a unique name that identifies the application or environment.
  3. Enter the AI provider endpoint and select the authentication method.
  4. Select Save.
    Confirm that the gateway status changes to Connected.
  5. Create an API key with the Gateway invoke scope.
  6. Send a test request using the API Reference.

The gateway is ready to accept test requests.

Verify the configuration

Confirm that the gateway returns an HTTP 200 response. If the request is blocked, review the security policy and event log.
