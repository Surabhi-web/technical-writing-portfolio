Create a Support Ticket

Create a ticket when you need assistance from the IT support team.

  1. Select New Ticket.
  2. Enter a short, descriptive subject.
  3. Select the most appropriate category.
  4. Describe the issue, including relevant error messages and the steps that led to the problem.
  5. Select Submit Ticket.
Tip: Include screenshots or other supporting files when they will help the support team understand the issue.
