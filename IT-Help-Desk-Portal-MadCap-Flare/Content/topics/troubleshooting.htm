Troubleshooting

Cannot sign in

  • Verify your username and password.
  • Check whether your account requires multi-factor authentication.
  • If the problem continues, contact IT Support.

Ticket submission failed

  • Check your internet connection.
  • Make sure all required fields are completed.
  • Try submitting the ticket again.

Attachment upload failed

  • Check the file size and supported file types.
  • Rename the file if it contains special characters.
  • Try the upload again.
